Methodology · v0.2

Open by design.

A serious index publishes its recipe. This is ours. v0.2 (10 Oct 2026) aligned all signals to the same UTC day, scores completed days only, and makes the components add up exactly to the score; past values were recalculated.

Step 1

Collect

Daily data from public sources: CoinGecko for price and volume (OKX as a backup), OKX for perpetual funding, DefiLlama for stablecoin supply. Only completed UTC days are scored.

Step 2

Normalise

Each raw signal maps to a 0–100 score by a fixed rule, so the same input always gives the same score.

Step 3

Weight

Scores combine with fixed weights. Momentum and leverage carry the most because they react fastest to the crowd.

Step 4

Publish

Each morning, after the UTC day closes, that day's score, components and raw inputs are added to a public archive. Archived days are never edited, so every number stays citable. Download it as CSV below.
